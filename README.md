A deadpan one-star review of sleep, in exactly 129 characters. The reviewer was given eight hours with a father who is no longer alive, then woken up and made to hand him back. No apology is accepted — only a refund will do.

## Run it

```sh
python3 main.py
```

Writes `entry.txt` (the review, exactly 129 bytes, no trailing newline) to `$OUTPUT_DIR` (default `/output`).
